# Glossary

IDE words, in one place.

| Term | Meaning |
|---|---|
| **IDE** | Integrated Development Environment: editor, build, run, debug and version control in one tool ([[ides/What an IDE Does]]) |
| **language server (LSP)** | a process that gives an editor code intelligence for a language |
| **indexing** | the IDE scanning your project to power search, navigation and completion |
| **inspection** | a check the IDE runs on your code (bug patterns, style) |
| **quick fix / intention** | an automatic change offered for a problem or at the cursor (<kbd>Alt</kbd>+<kbd>Enter</kbd>) |
| **SDK / JDK** | the toolkit the project is compiled against, e.g. JDK 21 ([[ides/Project Setup]]) |
| **language level** | which language version's features the compiler allows |
| **source root** | a folder the IDE treats as containing source code (`src/main/java`) |
| **run configuration** | a saved setup for launching an app or tests ([[ides/Running and Run Configurations]]) |
| **tool window / panel** | a docked area: terminal, debugger, Git, Gradle ([[ides/Anatomy]]) |
| **gutter** | the strip left of the code with line numbers, breakpoints and run icons |
| **breakpoint** | a marker where execution pauses in the debugger ([[ides/Debugging]]) |
| **logpoint** | a breakpoint that logs instead of pausing |
| **stack frame** | one method call on the call stack, with its own variables |
| **watch** | an expression the debugger re-evaluates at every pause |
| **step over / into / out** | run the next line, enter the called function, or finish the current one |
| **hot swap** | loading changed code into a running program without restarting |
| **remote debugging** | attaching the IDE's debugger to a program running elsewhere ([[ides/Debugging in Depth]]) |
| **refactoring** | restructuring code without changing what it does ([[ides/Refactoring]]) |
| **linter** | a tool that flags likely bugs and style problems |
| **formatter** | a tool that rewrites code layout consistently ([[ides/Settings and Formatting]]) |
| **EditorConfig** | a file that sets indentation and line endings for every editor |
| **snippet / live template** | a shortcut that expands into a code template ([[ides/Live Templates and Snippets]]) |
| **postfix completion** | IntelliJ templates typed after an expression (`list.for`) |
| **multi-cursor** | editing several places at once ([[ides/Editing]]) |
| **workspace** | the open project folder(s) plus their editor settings |
| **extension / plugin** | an add-on that adds features to the IDE ([[ides/Extensions and Plugins]]) |
| **debug adapter (DAP)** | the protocol that connects editors to language debuggers |
| **Local History** | IntelliJ's own record of file changes, independent of Git ([[ides/Git in the IDE]]) |
| **Dev Container** | a Docker-based development environment defined in the repository |
| **coverage** | which lines tests executed ([[ides/Testing in the IDE]]) |
| **ghost text** | an inline AI suggestion shown in grey ([[ides/AI in the IDE]]) |
| **agent** | an AI assistant that plans and performs multi-step changes |
