## Finding things
- Press <kbd>/</kbd> or <kbd>Ctrl</kbd>+<kbd>K</kbd>: results appear while you type and jump to the matching section.
- Word beginnings are enough (`rebas` finds *Rebasing*), and small typos are corrected.
- Paste an error message, e.g. `refusing to merge unrelated histories` or `Cannot read properties of undefined`, to land on the page that explains it.
- Use the search page's *In:* filter to search only one guide.

## How to read the pages
- **Code blocks** are copy-paste ready. A block directly after a command shows its real output.
- **Diagrams** show the idea; start there, then read the text.
- Each guide ends with **Common Errors**, a **Cheat Sheet** and a **Glossary**.
